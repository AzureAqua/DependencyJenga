    Dependency Jenga

    All modern digital infrastructure, resting on a few tiny blocks. Pull carefully.

    How it works

    We read the repo's dependencies and stack them into a tower: languages and runtimes at the bottom, leaf packages higher up (like xkcd 2347), and the project itself on top. Players take turns pulling a block out; whoever topples the tower loses.

    Every block's look comes from real data about that dependency and tells you how it behaves. Blocks with known CVEs start shaking after every turn a few rounds in, harder each round, so pull them out before they bring it all down.
